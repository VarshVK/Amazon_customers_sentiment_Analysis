Amazon_customes_sentiment_analysis
 Abstract—The challenge of sentiment analysis in Amazon
 customer reviews, with a focus on the ambiguity of three-star
 ratings. While one- and two-star ratings clearly indicate
 unhappiness, and four- and five-star ratings show contentment,
 three-star ratings can be difficult to interpret since they are
 equivocal. To address this, the research uses advanced Natural
 Language Processing (NLP) models like BERT to improve
 sentiment prediction accuracy. Unlike prior approaches,
 BERT’s bidirectional context awareness improves sentiment
 classification, particularly in nuanced reviews. The project also
 provides a comprehensive sentiment score system that goes
 beyond binary sentiment classification to recognize a variety
 of emotions such as wrath, joy, surprise, and trust. Machine
 learning models, including Logistic Regression, Na¨ ıve Bayes,
 and Support Vector Machines (SVM), are used.
 Using feature extraction methods like Term Frequency-Inverse
 Document Frequency (TF-IDF). Performance indicators like as
 accuracy, precision, recall, F-score, and cross-entropy are used
 to assess the models’ effectiveness in dealing with complicated
 sentiment categorization tasks. The project makes use of
 cloud-based computational resources to scale and analyze
 big datasets efficiently, allowing for the accurate analysis of
 thousands of evaluations.
 Index terms– Sentiment analysis, Amazon reviews, BERT,
 NLP, machine learning, TF-IDF, SVM, Google Colab, and
 emotional tone.
